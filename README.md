# نظام إدارة وتوزيع أسامة العزي — ملفات النشر

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الهيكل الرئيسي للتطبيق |
| `style.css` | التصميم والألوان |
| `app.js` | كل منطق النظام (المنتجات، الفواتير، الحسابات، التقارير) |
| `manifest.json` | يجعله قابلًا للتثبيت كتطبيق بأيقونة واسم |
| `sw.js` | يحفظ الملفات على الجوال ليعمل بدون إنترنت |
| `icon-192.png` / `icon-512.png` | أيقونة التطبيق |

> هذه الملفات هي **الكود فقط**. بياناتك (العملاء والفواتير) لا تُرفع إلى GitHub أبدًا، وتبقى على جوالك.

## قبل أي شيء: انقل بياناتك
المتصفح يحفظ البيانات لكل عنوان على حدة، فالعنوان الجديد سيبدأ فارغًا.
1. في النسخة الحالية: الإعدادات ← نسخة احتياطية ← «إنشاء ونسخ النسخة».
2. الصق النص في رسالة لنفسك (واتساب أو ملاحظات أو إيميل).
3. بعد التثبيت على العنوان الجديد: الإعدادات ← نسخة احتياطية ← الصق النص ← «استعادة».
(إذا كانت بياناتك تجريبية فتجاهل هذه الخطوة.)

## النشر على GitHub Pages (مجاني)
1. أنشئ حسابًا على github.com.
2. من علامة **+** أعلى الصفحة اختر **New repository**، اكتب اسمًا مثل `azzi-dms`، واختر **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب الملفات السبعة (بعد فك الضغط) إلى الصفحة، ثم **Commit changes**.
4. افتح **Settings ← Pages**. في **Source** اختر **Deploy from a branch**، والفرع **main** والمجلد **/ (root)**، ثم **Save**.
5. انتظر دقيقة أو دقيقتين، ثم يظهر رابط مثل `https://اسمك.github.io/azzi-dms/`.

## تثبيته على الجوال
- **أندرويد (Chrome):** افتح الرابط، ثم القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** افتح الرابط، ثم زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
افتحه مرة واحدة بالإنترنت ليحفظ ملفاته، وبعدها يعمل بدون إنترنت.

## تحديث النظام لاحقًا
ارفع الملفات المعدلة بنفس الطريقة (Add file ← Upload files)، فيصل التحديث لجوالك عند فتحه بالإنترنت. إذا لم يظهر فأغلق التطبيق وافتحه مرة ثانية.
